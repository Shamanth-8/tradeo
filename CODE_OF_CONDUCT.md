# Code of Conduct

Tradeo is a project about markets, where opinions run hot. This is how we keep
the project a good place to work.

## Expected

- Be respectful and assume good intent; critique code and results, not people.
- Back claims about strategies with data, and accept data that disagrees.
- Help newcomers — many contributors will be learning Python, trading, or both.
- Credit others' work, and respect the licences of anything you bring in.

## Not acceptable

- Harassment, insults, or discrimination of any kind.
- Promoting paid tips, "guaranteed returns", pump-and-dump schemes, or
  anything that could mislead someone into losing money.
- Sharing anyone's personal information, credentials or account details.
- Spam, including self-promotion unrelated to the project.

## Enforcement

Maintainers may edit or remove contributions and comments, and may block
people who break these rules. Report problems privately to the maintainers
(see [SECURITY.md](SECURITY.md) for how to reach them); reports are handled
confidentially.

This code applies in the repository, issues, pull requests and any project
discussion space. It is inspired by the
[Contributor Covenant](https://www.contributor-covenant.org/).
